## Tabel Perbandingan Platform

| Aspek | Web | Desktop | Mobile |
|---|---|---|---|
| Bahasa utama | HTML, CSS, JavaScript | C#, C++, Java, Python | Kotlin, Java, Swift |
| Arsitektur | Client-server, diakses melalui browser | Berjalan pada sistem operasi komputer | Berjalan pada sistem operasi perangkat mobile |
| Cara distribusi | Melalui server dan diakses menggunakan URL | Melalui installer atau toko aplikasi | Melalui Google Play Store atau Apple App Store |
| Keunggulan | Mudah diakses, lintas perangkat, pembaruan terpusat | Mendukung komputasi kompleks dan penggunaan offline | Praktis, mudah dibawa, mendukung kamera dan GPS |
| Keterbatasan | Fitur tertentu bergantung pada browser dan koneksi internet | Instalasi dan kompatibilitas berbeda antar sistem operasi | Terbatas oleh baterai, ukuran layar, dan variasi perangkat |
| Contoh aplikasi | Gmail Web, Google Docs Web | Microsoft Word, Visual Studio Code | WhatsApp, Google Maps |

## Refleksi

Platform yang paling menarik bagi saya untuk dipelajari adalah Mobile. Saya tertarik dengan pengembangan aplikasi mobile karena penggunaannya sangat dekat dengan kehidupan sehari-hari. Aplikasi mobile dapat membantu berbagai aktivitas, seperti komunikasi, pendidikan, transaksi, dan navigasi. Selain itu, saya ingin memahami bagaimana aplikasi memanfaatkan fitur perangkat seperti kamera, GPS, dan notifikasi. Saya berharap dapat mempelajari cara membuat aplikasi mobile yang bermanfaat dan mudah digunakan.

Tantangan terbesar saat melakukan setup environment adalah memastikan semua aplikasi dan tools pengembangan terpasang serta dapat berjalan dengan benar. Setiap tools memiliki fungsi dan konfigurasi yang berbeda. Misalnya, Git digunakan untuk mengelola versi kode, Node.js dan NPM mendukung pengembangan JavaScript, sedangkan Java JDK diperlukan untuk pengembangan berbasis Java. Selain itu, penggunaan GitHub dan proses clone repository juga membutuhkan pemahaman mengenai perintah dasar Git.

Untuk mengatasi tantangan tersebut, saya akan mempelajari dokumentasi resmi dari setiap tools, mengikuti panduan instalasi secara bertahap, dan memeriksa versi aplikasi melalui terminal. Jika mengalami kesalahan, saya akan membaca pesan error dan mencari solusi melalui dokumentasi atau sumber belajar tepercaya. Saya juga akan rutin berlatih menggunakan Git dan GitHub agar lebih terbiasa mengelola repository. Dengan latihan yang konsisten, saya berharap dapat meningkatkan kemampuan dalam menyiapkan environment dan mengembangkan aplikasi secara mandiri.
